## Browsers

Glossen uses `localStorage`, the `storage` event and the [Web Locks API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Locks_API) to coordinate tabs. Without Web Locks, it falls back to a heartbeat saved with each conversation.
