## Styling

The components use Fumadocs theme tokens such as `bg-fd-background` and `text-fd-muted-foreground`, so they follow your Fumadocs theme and dark mode without extra CSS. Glossen does not add a global theme.

`AskAIPanel` and `AskAITrigger` accept `className`. `AskAITrigger` also accepts children to replace its label:

```tsx
<AskAITrigger className="bottom-6">Ask the docs</AskAITrigger>
```

The panel is a right-side overlay from the `lg` breakpoint and an inset dialog on smaller screens. It is 400px wide (440px from `2xl`). Change `--glossen-width` in `components/glossen/ask-ai.tsx` to adjust.

## Keyboard shortcuts

| Keys                                  | Action                                                   |
| ------------------------------------- | -------------------------------------------------------- |
| <Shortcut mac="⌘ /" other="Ctrl /" /> | Open or close Ask AI                                     |
| <kbd>Esc</kbd>                        | Close Ask AI, or cancel editing                          |
| <kbd>Enter</kbd>                      | Send (<kbd>Shift</kbd> <kbd>Enter</kbd> adds a new line) |
| <Shortcut mac="⌥ A" other="Alt A" />  | Attach the selected documentation text                   |
