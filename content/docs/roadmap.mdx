---
title: Roadmap
description: Features that are planned but not part of this release.
---

These features are **not available** in this release:

- **File attachments** such as images, PDFs and code files.
- **Speech-to-text** through a separate transcription route.
- **Automatic context compaction** for conversations that outgrow the model's context window.
- **Conversation branches**, renaming conversations and queued messages.
- **Server-saved history**, syncing across devices, and answers that keep generating after the browser closes.
